## 📌 About the Internship

The internship focused on practical applications of **Artificial Intelligence, Machine Learning, and Natural Language Processing (NLP)**. As part of the internship, I worked on a **Spam Email Classifier** for automatically distinguishing legitimate customer emails from spam.

The project covered data cleaning, text preprocessing, feature engineering, machine learning model training, model comparison, evaluation, and model improvement techniques. The internship was conducted as a **1-month hybrid internship from 10 June 2026 to 10 July 2026**.

---

## 🎯 Objectives

* Collect labeled spam/ham email data
* Remove duplicate and empty records
* Clean and preprocess email text
* Apply NLP preprocessing techniques
* Generate TF-IDF features
* Create word and character n-grams
* Engineer email metadata features
* Train and compare multiple machine learning models
* Apply hyperparameter tuning and ensemble methods
* Evaluate models using accuracy, precision, recall, F1-score, and confusion matrix
* Analyze classification errors and improve model robustness
